## 2. Физические характеристики GOLD-релиза:

1. **Частота развёртки ровно 100.00 FPS (Время кадра 10 000.9 мкс):**
   - **Нулевое мерцание боковым зрением:** частота 100 Гц полностью превышает порог слияния мельканий человеческого глаза (Critical Flicker Fusion, ~60–80 Гц).
   - **Нулевые биения с электросетью (Zero-Beat Mains Sync):**
     $$100.0\text{ Гц (матрица)} - 100.0\text{ Гц (пульсации БП 50 Гц)} = \mathbf{0.00\text{ Гц}}$$
     Бегающая стробоскопическая полоса физически полностью отсутствует.
2. **Полный заводской профиль из 19 регистров Depuwei:**
   - **`0x063A`:** высокоскоростной умножитель PLL ($11\times$).
   - **`0x0B27`:** низкое напряжение перегиба источника тока $V_{knee}$ для максимальной отдачи тока в светодиоды.
   - **`0x08FF`:** максимальный ток $I_{GAIN} = 255 / 255$ (200% шкалы).
   - **`0x0CD8`:** режим расширенного тока High-Current Range.
   - **`0x0E27` и `0x0F20`:** аппаратные токовые бустеры и множители ШИМ.
   - **`0x1180`:** режим форсированной эффективности ШИМ.
3. **Безупречная геометрия и чёткость:**
   - Ровно 128×64 пикселей без смещения, без размытия, без паразитного эха (ghosting) и без полосы на 32-й строке.
   - Полноценная поддержка 64 КБ буфера кадров в быстрой внутренней памяти SRAM.
